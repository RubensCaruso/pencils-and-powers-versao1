FUNÇÕES DIRETAS VIA TECLADO (Sugiro uso do Teclado Numérico Lateral):

[ SETAS ]; = Movimento fino da carta
[ delete ]; = Manda carta para deck de descarte
[ , ] = Manda carta para deck de descarte
[ + ] = Aumenta o tamanho da carta
[ - ] = Diminui o tamanho da carta
[ CTRL + ] = Zoom + na mesa
[ CTRL - ] = Zoom - na mesa
[ 4 ] = Rotaciona para a esquerda
[ 6 ] = Rotaciona para a direita
[ E ] = Abre popup com carta para visualizar melhor
[ T ] = Trava ou destrava uma carta no fundo da mesa
[ D ] = Duplica uma carta na mesa
[ G ] = Agrupa Cartas sobrepostas para movimento da pilha
[ 8 ] = Vira a carta, mostrando seu verso
